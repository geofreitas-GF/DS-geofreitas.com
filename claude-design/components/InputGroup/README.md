Adds a prefix, suffix or clear button to any input. The group draws the border, hover and focus halo; the input inside is borderless.

**Provide:** `<div class="gf-input-group">` with optional `.gf-input-group__affix` before or after the `.gf-input`, and an optional `.gf-input-group__clear` button (`aria-label`, needs a `placeholder` on the input so it hides when empty).

**Do:** use affixes for fixed parts (`https://`, `£`, `GBP`). **Don't:** put a label inside the affix.
