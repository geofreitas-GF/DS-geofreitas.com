A persistent, full-width notice about a project-wide state that needs resolving — overdue billing, an active rollback, attack mitigation. Never dismissable: if a message can be dismissed without the state resolving, use Alert instead. Show only one at a time.

**Provide:** `<div class="gf-banner gf-banner--warning">` with a leading icon, `.gf-banner__text` and an optional `.gf-banner__cta` button. Variants: default (neutral), `--success`, `--warning`, `--error`.
