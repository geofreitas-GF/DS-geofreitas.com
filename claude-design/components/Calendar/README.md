The date panel for prototypes: month navigation and a 7-column grid of round day buttons.

**Provide:** `.gf-calendar` → `__head` (icon buttons + `__title`), `__grid` of `__dow` labels and `<button class="gf-day">` (`aria-current="date"` today, `aria-selected="true"` selection, `--in-range`, `--outside`, `disabled`). In production forms use `<input class="gf-input" type="date">`.
