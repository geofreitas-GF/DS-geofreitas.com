A tonal content panel, and `--float`: the sticky action panel (the system's one floating surface) that becomes a bottom bar under 820px.

**Provide:** `<div class="gf-panel">`; or `<aside class="gf-panel gf-panel--float">` with a title block, one primary button and any `.gf-panel__extra` items (hidden in the mobile bar).

**Do:** use `--float` for one persistent action per page (contact, book, download). **Don't:** float more than one panel; add shadows to plain panels.
