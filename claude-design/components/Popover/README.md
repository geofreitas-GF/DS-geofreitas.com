A light-dismiss panel for rich content: filters, a short form, details.

**Provide:** a trigger with `popovertarget` and `<div class="gf-popover" id popover>`; close from inside with `popovertargetaction="hide"`. 320px wide, `gf-shadow-raised`.

**Don't:** use for blocking decisions (use `Dialog`) or for one-line hints (use `Tooltip`).
