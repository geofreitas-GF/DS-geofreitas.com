Loading indicators: `.gf-loader` spinner (icon-sized, `--lg` 40px) for in-place work, `.gf-loader-mark` (the brand loading mark, breathing) for page or app loads, and the button's own `aria-busy` state for actions.

**Provide:** `role="status"` and an `aria-label`. Use skeletons, not spinners, for layout that is loading.
