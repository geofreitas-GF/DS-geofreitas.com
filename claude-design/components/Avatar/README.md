The protected Raggio letter avatar: a `gf-raggio` circle with `gf-on-raggio` 600 initials, in 32 / 40 / 48px.

**Provide:** `<span class="gf-avatar">` (+ `--sm` / `--lg`) with two initials, or an `<img>` inside; decorative avatars next to a visible name take `aria-hidden="true"`.

**Don't:** recolour, square or border it; place several avatar groups in one view (the group is the view's Raggio moment).
