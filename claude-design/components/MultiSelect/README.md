A trigger button that opens a listbox of checkable rows; the trigger summarises the selection ("None selected" / one name / "n selected" / "All selected"). Simplified from Vercel's two-axis keyboard model: here the row itself (`role="option"`) is the one focusable, selectable unit — moved with ↑/↓/Home/End, toggled with Enter/Space/click — and the checkbox is a decorative echo of `aria-selected` (`aria-hidden`, `tabindex="-1"`).

**Provide:** `.gf-multiselect` > trigger `button[aria-haspopup=listbox]` + `.gf-multiselect__list[role=listbox][aria-multiselectable=true]` of `.gf-multiselect__row[role=option]` (checkbox, label, optional `.gf-multiselect__action` "Only" shown on hover/focus). Esc or an outside click closes; Tab closes and moves on. Fires `gf-change` with `detail.values`.
