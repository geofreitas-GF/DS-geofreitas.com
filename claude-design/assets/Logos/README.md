geO freitas marks, copied from geofreitas.com. Use them as they are: never redraw, recolour or stretch them.

- `wordmark-black.svg` is the primary wordmark, used in the nav and footer on light grounds. Its ink is black with the Raggio dot, and it can't inherit colour, so swap the file for dark.
- `wordmark-white.svg` is the same wordmark in white ink, for dark grounds (`data-theme="dark"`).
- `loading-mark.svg` is the small mark for loaders and tight spaces.
- `favicon.svg` is the browser tab icon.
- `footer-logo-black.png` is the raster footer lockup. Use it only where SVG isn't possible.
