# Legacy system — archived (superseded by 1.0.0, 2026-11-18)

The pre-1.0 system, generated by OpenDesign. Nothing in 1.0 depends on these files. They are kept for history and as starting points for layouts 1.0 does not cover yet.

| Folder | What it is |
| --- | --- |
| `kits/` | `kit.html` and `kit.dark.html`, the original component kits where the protected hover states were first designed. They now live in `components/components.css`. |
| `samples/` | Generated sample pages: landing, deck, email, newsletter, poster and form. Landing is replaced by `examples/landing.html`; the other five are still useful to rebuild on 1.0. To restyle one with 1.0 tokens, load `tokens/legacy-compat.css` after `tokens/variables.css`. |
| `generator/` | The retired OpenDesign generator output: seed, theme, `tokens.*.json`, `variables*.css` and the fix-up scripts. It can't rebuild, because its `brand.json` was deleted. |
| `docs/` | The legacy `DESIGN.md` and `README.md`, `guide.md` (a duplicate of `BRAND.md`), and the OpenDesign handoff and manifest. |

Font paths in `kits/` and `samples/` point to `../../../assets/fonts/`, so they still open correctly from here.
